# CIE-budget

Budget Analyzer Program
What it does
This is a program I made to check monthly budgets.
You can enter your monthly income, fixed expenses, variable expenses, savings goal, unexpected costs, and your budget limit.
You can add multiple months of data, and then analyze them together.
The program shows if you are overspending or within budget each month. It also gives tips to save money, and shows a graph comparing your income, spending, and budget across months.

Features
Multiple Months: Add as many months of data as you want.
Status Report: Tells you if you are Within Budget, Over Budget, or Overspending.
Health Check: Shows your financial health as Stable, Caution, or Critical.
Helpful Tips: Suggests where you can save more.
Graph: Draws a chart with your Income, Spending, and Budget for each month.

How to Run It
Install the requirements
Open your computer’s terminal/command prompt and run:

pip install -r requirements.txt

If you don’t want to use requirements.txt, you can just install manually:
pip install PyQt5 matplotlib

Run the program
In the same terminal, run:

python budget_analyzer.py

The program window should now open. You can start typing your numbers, add months, and click “Analyze” to see the results and graph.
